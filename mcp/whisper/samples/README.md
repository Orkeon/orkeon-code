# Samples

`fr-5s.wav`: five seconds of French, 16 kHz mono PCM, from "FR Dérive (empennage).ogg" on
Wikimedia Commons (Raminagrobis, Spoken Wikipedia, CC0 public domain dedication), seconds 30 to 35,
resampled with PyAV. The `tiny` model hears "dérive" in it; `scripts/whisper-mcp-smoke.sh` checks that word.
